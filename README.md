# 听力预算台（hearing-budget）

把一天里几段吵闹按各自的「允许时长」折算，算出暴露剂量与等效 8 小时声级；点名最吃预算的一段，并给出回到上限内的最小改动。

- 允许时长 `T(L) = 8h × 2^((基准 − 声级) ÷ 交换率)`；剂量 `D = Σ 该段小时数 ÷ T(L_i)`
- 等效 8 小时声级 `L_EX = 基准 + 交换率 × log2(D)`；另给严格的等能量口径 `10·log10(Σ t_i·10^(L_i/10) ÷ 8h)` 作对照
- 剩余额度 `(1 − D) × T(追加声级)`；超限时用闭式解反推「只改一项」要降多少 dB / 减多少分钟，并把解回代重算到 100%
- 参考换算：多声源同时响（能量相加，两个相同 → +3.01 dB）、自由场点声源距离衰减（距离加倍 → −6.02 dB）
- 纯前端单文件：`core.js`（算术，无 DOM）+ `ui.js`（界面）+ `template.html`，`node build.cjs` 生成 `index.html`

## 边界

只做暴露剂量算术：不做医学诊断、不评估已有听力状况、不给治疗或防护用品选型建议；不处理脉冲噪声、低频专项、个体易感性与年龄差异；不处理耳塞耳罩标称衰减值换算；距离衰减只适用自由场点声源；声级全部由用户填写，页面不测量、不联网、不内置任何场所的实测数据；判定分组只是显示分组，不是法规或科学边界。默认样例与 5 个内置场景均为虚构示例。
