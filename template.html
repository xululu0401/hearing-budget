HEARING BUDGET LEDGER · 噪声暴露剂量与听力预算

今天这些吵闹，加起来用掉了多少听力预算？

「85 分贝能待 8 小时」只是一个声级的说法。真实的一天是几段不同的声音拼起来的：地铁 50 分钟、耳机 90 分钟、餐厅 1 小时。听力预算台把每一段的声级换算成各自的「允许时长」，再算出总剂量与等效 8 小时声级：今天用掉了上限的百分之多少、哪一段吃掉最多、还能再听多久、要回到上限内该把哪一项降几个 dB 或减多少分钟。默认样例是一份虚构的通勤日记录。

算法与使用边界（每个数字的口径都在这里）

允许时长：T(L) = 8 小时 × 2^((上限基准 − L) / 交换率)。选 3 dB、基准 85 dB(A) 时，85 dB 是 8 小时、88 dB 是 4 小时、91 dB 是 2 小时、94 dB 是 1 小时——这就是「每高 3 dB，允许的时间减半」。选 5 dB 交换率时是「每高 5 dB 减半」。

剂量：每一段算 该段小时数 ÷ 该声级的允许时长，再把所有段相加。剂量 100% 表示刚好用满所选口径的上限。本页只是把先后发生的几段暴露相加，不处理同时发生、也不处理中间休息的恢复效应。

等效 8 小时声级：L_EX = 上限基准 + 交换率 × log2(剂量)。它把「一天里高低起伏的几段」压成一个数——相当于连续听这个声级 8 小时。剂量为 0 时它没有定义，页面显示「—」。

口径对照（重要）：本页同时算一个等能量口径 10·log10(Σ 小时数 × 10^(L/10) ÷ 8)。3 dB 交换率并不等于严格的等能量（严格等能量是 10·log10(2) ≈ 3.0103 dB），所以两个口径会差一点点（页面上给了差额）。另外，3 dB 口径在高于基准的声级上比 5 dB 口径严，在低于基准的声级上反而更宽松——换口径可能直接改变「超没超」的结论。所以看任何「安全时长」的说法，先问清是哪个交换率、哪个基准。

剩余额度与反推：没超上限时，页面算「按追加声级还能听多少分钟」，公式是 (1 − 剂量) × T(追加声级)，并把它回代验证过（再听这么多分钟恰好用满 100%）。超上限时，页面逐个条目解出「只改这一项」的两个选择：把声级降 交换率 × log2(本项剂量 ÷ 改后应有的剂量) 个 dB，或把时长按比例减到某个分钟数；两项都做了回代验证。如果某一条目即使降到 0 dB(A) 也回不到上限内，页面会直接判「单靠这一项做不到」，让你改多项。

参考换算：多个声源同时响时按能量相加 10·log10(Σ 10^(L/10))——两个一样的声级合起来只涨 3.01 dB，不是数值相加；自由场点声源距离衰减 L(r2) = L(r1) − 20·log10(r2/r1)，距离加倍是 −6.02 dB。这两项只做换算，不改动上面的暴露清单。

做不到的：本页不做医学诊断，不评估你已有的听力状况，不给治疗、用药或防护用品选型建议；不处理脉冲噪声（枪声、鞭炮、爆炸这类峰值声压与 C 计权）、不处理次声与低频专项、不处理个体易感性与年龄差异；不处理防护用品（耳塞/耳罩）的标称衰减值换算（NRR/SNR 与实际佩戴效果差距大，本页不做换算）；距离衰减只适用自由场点声源，不处理室内混响、线声源（每距离加倍约 −3 dB）、地面反射与隔声结构的实际隔声量；声级全部由你填，本页不测量、不联网、不内置任何设备或场所的「实测」数据；判定分组（余量充足 / 接近上限 / 已超 / 远超）只是本页为了让结论可读而设的显示分组，不是法规或科学边界；上限基准与交换率都是你选的口径，本页不宣称哪一个才是标准。默认样例与 5 个内置场景全部是虚构示例，其中数字只是演示用，不代表任何真实场所的实测声级。
